MaLa v2.0 — Coming

► IN DEVELOPMENT MaLa v2.0 is currently in active development — a ground-up rebuild targeting modern Windows systems.

MaLa v2.0 — In Development
What's New
  • Complete rebuild in Delphi 13 — modern compiler, modern codebase
  • Fully backward compatible — your existing v1.74 configs, layouts, and plugins will continue to work
  • Target platform: Windows 10 and Windows 11 (32-bit)
  • Improved stability and crash resistance throughout
  • Updated video engine using FFVCL
  • Native support for IOWarrior LCD and LED hardware
  • Many more built-in emulator presets added — setting up a new emulator is now just a couple of clicks
  • Updated plugin API with improved event system — SDK examples for C++ and Delphi
  • Modernised UI with VCL Styles support
  • Companion tools (Layout, GameList, Tree, AttractMode) rebuilt and being combined into a single unified MaLaTools app — one app instead of four, shipping with the final v2.0 release
  • New tools: MaLaControlCmd (command-line) and MaLaControlGui (graphical) — send commands to a running MaLa instance
Timeline

No release date set. Development is progressing through a structured multi-pass stabilisation plan. Watch this page and the BYOAC Forum for updates.

► WHY NO SCREENSHOTS YET MaLa's layouts and gameplay screens are staying visually the same by design — your existing layouts will look and feel exactly as they do now. What's actually changing is under the hood, plus the menus, config windows and splash screens. We'll share screenshots of those once Beta 1 testing is underway.
