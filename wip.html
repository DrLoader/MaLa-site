MaLa v2.0 — Coming

► IN DEVELOPMENT MaLa v2.0 is currently in active development — a major modernisation of the existing MaLa codebase for modern Windows systems.
► BETA 1 TESTERS WANTED A limited MaLa v2.0 Beta 1 test release is currently targeted for mid-September 2026, pending final validation. Development has moved into structured testing: validating layout rendering, hardware compatibility (LED/LCD boards), and emulator launching across multiple MAME versions.

Interested in testing? Reply on the BYOAC Forum thread with your current setup.
MaLa v2.0 — In Development
What's New
  • Complete rebuild in Delphi 13 — modern compiler, modern codebase
  • Backward compatible by design — existing v1.74 configs and layouts are intended to continue working, and existing .mplugin plugins are expected to remain compatible, pending final verification
  • Target platform: Windows 10 and Windows 11, including 64-bit Windows; MaLa remains a 32-bit application
  • Improved stability and crash resistance throughout
  • Updated video engine using FFVCL
  • Native support for IOWarrior LCD and LED hardware
  • Many more built-in emulator presets added — setting up a new emulator is now just a couple of clicks
  • Updated plugin API with improved event system — SDK examples for C++ and Delphi
  • Modernised UI with VCL Styles support
  • Companion tools (Layout, GameList, Tree, AttractMode) rebuilt and being combined into a single unified MaLaTools app — one app instead of four, shipping with the final v2.0 release
  • New tools: MaLaControlCmd (command-line) and MaLaControlGui (graphical) — send commands to a running MaLa instance
Timeline

No date has been set for the final v2.0 release. Beta 1 is currently targeted for mid-September 2026, pending final validation. Development is progressing through a structured multi-pass stabilisation plan. Watch this page and the BYOAC Forum for updates.

► WHY NO SCREENSHOTS YET MaLa's layouts and gameplay screens are staying visually the same by design — your existing layouts will look and feel exactly as they do now. What's actually changing is under the hood, plus the menus, config windows and splash screens. We'll share screenshots of those once Beta 1 testing is underway.
► DISCLAIMER MaLa v2.0 is still under active development. Features and implementation details may change as testing continues. The core goal of maintaining compatibility with existing MaLa layouts, configurations and plugins remains unchanged.
